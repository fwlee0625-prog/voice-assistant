# 项目模块与功能拆分

梳理日期：2026-10-29。依据当前工作区源码、页面路由和接口实现整理，包含尚未提交的代码。本文是功能盘点，不代表已完成现场验收；本次未启动服务或调用真实云端模型。

## 范围与状态

- 当前主链路：`frontend-test/` 的 `/record` 页面 → `server/` Express 后端（8020），衔接词决策通过 HTTP 调用 `model-service/`（8030）。
- 当前前端只有一个业务页面：语音对话页；设置为该页面内的弹框。
- “当前”：已在当前页面或主链路实现；实际可用仍依赖权限、配置、模型资产和供应商服务。
- “接口保留”：有后端实现，但当前页面没有入口。
- “历史保留”：位于旧 `backend/`、`web/`，未接入当前主链路。
- “待接入”：当前主链路没有实现，不应列为现成功能。

## 第二步：功能拆分

### M01 语音对话界面

| 功能编号 | 功能 | 当前行为 |
| --- | --- | --- |
| M01-F01 | 手动开始与结束 | 点击开始对话申请麦克风并连接识别；手动结束处理已完成的尾句 |
| M01-F02 | 语音状态展示 | 展示待机、唤醒准备、聆听、识别、思考、回答、等待继续、结束等状态 |
| M01-F03 | 语音舞台展示 | 动态球体、粒子、声波等效果随交互状态与麦克风音量变化 |
| M01-F04 | 当前文本展示 | 单行区域展示通过交互门控的识别文字及当前回答 |
| M01-F05 | 对话记录展示 | 侧栏展开/收起，气泡显示当前会话问答及异常状态；新对话替换旧会话，刷新清空 |
| M01-F06 | 错误反馈与重试入口 | 提示麦克风、识别、模型与播报异常，提供回答失败重试入口 |

### M02 音频采集与预处理

| 功能编号 | 功能 | 当前行为 |
| --- | --- | --- |
| M02-F01 | 麦克风权限与资源管理 | 请求授权，处理设备不支持等异常；结束或离开页面释放对应音频资源 |

### M03 语音唤醒

| 功能编号 | 功能 | 当前行为 |
| --- | --- | --- |
| M03-F01 | 本地唤醒待机 | 用户开启后在浏览器运行中文 KWS；待机不连接云端 ASR |

| M03-F04 | 对话与待机切换 | 手动结束、普通语音退出或空闲超时后，在唤醒已开启时返回待机；支持关闭唤醒 |
| M03-F05 | 防重复触发与播报抑制 | 唤醒应答及对话收尾期间协调监听状态，避免提示音和尾音再次触发 |

### M04 实时语音识别

| 功能编号 | 功能 | 当前行为 |
| --- | --- | --- |
| M05-F01 | 建立与切换交互人 | 手动开始或本地唤醒后以首个稳定说话人建立交互；其他人明确呼叫可切换 |
| M05-F02 | 旁人及不稳定话语过滤 | 不稳定说话人暂等，旁人话语按规则忽略，避免混入同一个问题 |

## 任务整理时的使用方式

上述功能编号可直接作为任务归属。一个功能可以再拆成多条实施任务，但模块和功能层级保持稳定。

建议任务字段：任务编号、模块、功能编号、具体问题/目标、当前状态、验收标准、依赖、优先级、负责人。

例如：M05-F04 下的“球房噪声下说完判断调优”，验收标准应描述测试场景和可测结果；不能仅写“优化 Smart Turn”。当前没有现场测试数据，不预填准确率或时延目标。

需要独立列入后续需求评估的事项：当前主链路接入台球 RAG、推荐/模拟/摆球工具、跨页面球局状态同步、对话历史持久化，以及真实球房环境下的唤醒、旁人过滤和打断效果验收。前四项当前没有在主链路实现；最后一项是已有能力的效果验证。
