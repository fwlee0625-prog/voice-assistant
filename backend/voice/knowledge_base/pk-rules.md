# PK 中式八球玩法规则知识库

> 版本：2026-09-23。已确认的 PK 中八玩法规则；单局中八基础判罚见同目录 [rules.md](./rules.md)。

## 适用范围

- PK 中八按局计分，分为**平打、让球、让局、弹性让球**四种独立模式。
- 中八玩法仅支持 **1v1 或 2v2**。

## 平打

- 不设置让球或让局，按中八单局胜负累计局分。

## 让球

让球分为**前 N 球**和**后 N 球**。取走的是受让方本方的非黑 8 目标球；黑 8 仍须合法击入。

### 前 N 球

1. 双方完成定色后，**紧接着的下一杆开始前**，取走受让方本方约定的 `N` 颗球。
2. 不论下一杆轮到哪一方，都在该杆开始前完成取球。

### 后 N 球

1. 当受让方本方球**剩余对应数量 `N` 颗**时，在**受让方下一杆开始前**取走对应的 `N` 颗，再按规则击打黑 8。
2. 若未取或忘记取，受让方继续按正常规则打完剩余本方球，再合法击打黑 8。

## 让局

- 开局前设置抢局数 `R`、让局方与让局数 `H`。让局数必须小于抢局数，最大为 `R−1`。
- 进入对战时，让局方初始局分为 `0`，受让方初始局分为 `H`。其后每赢一局，胜方局分加 1；先达到 `R` 者赢得整场。

## 弹性让球

- 弹性让球仅给当前局分落后方，双方平分时不让球；形式为**后 1 球至后 3 球**，取球时点沿用“后 N 球”。
- 弹性让球数大于 1（后 2 或后 3）的前提是受让方**连续落后**；不能仅凭当前局分差升到后 2 或后 3。

## 2v2 队内轮换

- 本队一名队员击球后，若球权仍在本队，下一杆由另一名队员击球。连续合法进球时也逐杆更换队友，按 A1→A2→A1、B1→B2→B1 交替。

## 球色分配

- 本规则适用于所有需要分配全色／花色的 PK 对局。本局第一杆有球进袋后仍不定色，进球方继续击打第二杆；2v2 的第二杆按队内逐杆轮换由队友击打。
- 第二杆进球后，确定双方球色。
- 第二杆未进球时，球色仍未确定，球权交给对方；对方进球后选择全色或花色，另一方归属另一球组。
